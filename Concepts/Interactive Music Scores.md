concept: Interactive Music Scores
date_first_seen: 2026-08-09
---

Unlike a traditional printed score that plays out in one fixed, linear order, an interactive score is a computer-readable set of instructions where the timing and triggering of musical or media events can follow flexible, rule-based relationships — for example "play this only after that sound finishes" — instead of a strict fixed timeline. This lets a live performance or an interactive installation shape how a piece actually unfolds each time.
