Faust is a specialized programming language designed specifically for writing audio processing code — synthesizers, effects, filters — using compact mathematical-style expressions instead of general-purpose code. A Faust program can be compiled to run in many different environments: as a plug-in, in a web browser, or on small embedded hardware, which makes it a popular tool for researchers and instrument builders who want their audio designs to be portable.
