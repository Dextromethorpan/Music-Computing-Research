Digital audio coding is the set of techniques for turning sound into digital data (a string of 1s and 0s) so it can be stored or transmitted, and for turning that data back into audio a listener can hear. Different coding schemes make different trade-offs between audio quality, file size, and how tolerant the format is to errors or damage in storage — for example, the "Eight-to-Fourteen Modulation" scheme used on audio CDs was specifically designed to avoid bit patterns that a CD player's laser might misread, so that the disc still plays correctly even with small scratches or dust.
