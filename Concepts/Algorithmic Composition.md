concept: Algorithmic Composition
date_first_seen: 2026-08-10

Algorithmic composition means using a set of rules, mathematical formulas, or a computer program to generate musical material — such as which notes to play, in what rhythm, or how loud — instead of a composer writing every note by hand. This idea predates modern AI by decades: in the 1960s, composers like Iannis Xenakis used probability theory and early mainframe computers to generate scores by feeding rules into a program (an early example was Xenakis's "STOCHOS" system, built at Indiana University). Today's AI music generation tools are, in a sense, a modern continuation of this same basic idea — letting a system's rules or learned patterns produce musical decisions rather than a human making every one directly.
