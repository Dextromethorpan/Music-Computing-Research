concept: Tangible User Interfaces (TUI)
date_first_seen: 2026-08-09
---

A tangible user interface (TUI) lets you control a computer program by physically touching, moving, or rearranging real objects — like wooden blocks on a table — instead of only tapping a touchscreen or clicking a mouse. A camera or sensor tracks the objects' position and orientation and feeds that information to software, which reacts in real time. In music, this idea is used to build instruments where you can see and grab the actual "pieces" of a sound-generating patch, making both the playing and the underlying structure visible and shareable among several people at once.
