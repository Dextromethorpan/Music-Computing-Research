Live coding is a performance practice where a musician writes and edits computer code in real time, on stage, and the code itself generates the sound the audience hears as it changes. Instead of pre-writing a whole piece of software and simply pressing play, the performer adds, tweaks, or deletes lines of code while the music keeps playing — a bit like changing a recipe while the dish is already cooking. This requires programming languages specifically designed for extremely precise timing and the ability to change running code without crashing or breaking the beat; ChucK, created at Princeton, is one of the best-known examples of such a language.
