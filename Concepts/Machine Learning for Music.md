This is the broad application of machine learning — training a computer model on examples rather than programming explicit rules — to musical tasks such as recognizing which technique a guitarist is using, generating new material, or extracting information from tablature. It's the general umbrella under which many more specific techniques in this vault (like source separation or pitch estimation) sit.
