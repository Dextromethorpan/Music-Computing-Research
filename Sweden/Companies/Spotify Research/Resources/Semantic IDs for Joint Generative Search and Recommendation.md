This paper proposes representing each song or podcast as a compact code that captures its meaning (a "semantic ID"), so that one single AI model can handle both search — finding content that matches what you typed — and recommendation — suggesting content you didn't ask for but might like. Normally these are two separate systems; combining them into one model is meant to make both more consistent and easier to improve together.
