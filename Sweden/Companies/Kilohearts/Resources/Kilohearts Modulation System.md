Kilohearts built a single, unified modulation system shared across all of their plugins: almost any knob or setting can be "wired up" to a modulation source — an envelope, an LFO (a slow oscillator used to create rhythmic changes), a random generator, or even a performance input like how hard a key was pressed. What makes it a real technical design choice rather than a standard feature is that the same small set of modulator modules works identically whether you're inside a synth (Phase Plant), a multiband effect (Multipass), or the free-form effects chain (Snap Heap) — plus it distinguishes between fast "audio rate" modulation (updated every sample) and cheaper "control rate" modulation (updated roughly every 64 samples), letting the system stay efficient without giving up expressive detail where it matters.
