This is the open-source code repository accompanying the group's collaborative-watermarking research (see the two related papers in this folder). It provides the actual training scripts and model code that researchers can use to reproduce or build on the method for making AI-generated speech carry a hidden, machine-detectable signature — a practical building block for anyone working on deepfake-speech detection or responsible generative-audio systems, not just a description of the idea in a paper.
