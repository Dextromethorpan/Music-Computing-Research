Aural ID is Genelec's software for making studio-quality mixing possible on ordinary headphones. It works by capturing a personal HRTF (head-related transfer function — a description of how a specific person's head and ear shape change sound depending on its direction) for the individual user, then using that personal profile to process audio so headphones "sound like" trusted studio loudspeakers in a real room, including realistic width, depth, and tonal balance. This matters because a generic (non-personalized) binaural simulation can sound noticeably wrong for many listeners, since everyone's HRTF is a little different; Aural ID's per-person calibration is aimed at closing that gap so mixing engineers can trust what they hear on headphones away from the studio. It's part of Genelec's wider UNIO monitoring ecosystem, alongside their GLM room-calibration software.
