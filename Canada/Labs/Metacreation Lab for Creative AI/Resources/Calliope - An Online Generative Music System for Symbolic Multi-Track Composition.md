Calliope is a web app that turns the MMM generative model (see the MMM paper) into something a composer can actually click around in, rather than a piece of research code. A user uploads a MIDI file (a digital score, not audio), sees each instrument track laid out visually, and can ask the AI to either fill in gaps in an existing track or generate entirely new tracks that fit the rest of the piece — a process called "symbolic" composition because the system works with musical notation-like data rather than raw sound waves. "Multi-track" generation can be run in batches, so a composer can generate several candidate versions of a passage and audition them by ear before picking one, similar to browsing several draft options rather than getting stuck with the AI's first guess. Calliope was first presented at the International Conference on Computational Creativity (ICCC) in 2022 and later evaluated with real composers to see how usable and useful the workflow actually is.
