This is the live, actively hosted code repository for Marsyas, the audio-analysis software George Tzanetakis started as a PhD student and continues to develop at MISTIC. It is released as free software (GNU General Public License), meaning anyone can download, inspect, modify, and redistribute it at no cost. Written mainly in C++ for speed, with bindings so it can be called from Python and other tools like Max/MSP and Pure Data (popular environments musicians and sound artists use to build interactive audio patches), Marsyas packages decades of MIR research techniques — feature extraction, classification, similarity search — into reusable software components. For a beginner, this GitHub page is the best place to see what "doing music computing research" actually produces in practice: not just papers, but working, downloadable tools.
