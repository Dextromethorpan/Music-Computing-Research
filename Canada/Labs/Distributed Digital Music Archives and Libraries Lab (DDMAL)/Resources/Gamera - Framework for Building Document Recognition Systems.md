Gamera is an open-source software framework for building custom "document recognition" programs — software that looks at a scanned image and identifies structured symbols within it. It was originally created with heavy involvement from Ichiro Fujinaga and DDMAL for recognizing historical music notation, but it is general enough to have been reused for other tasks, like reading old handwritten text or maps. Instead of being a single ready-made recognizer, Gamera gives developers a toolkit — image processing functions, a classifier for sorting detected symbols into categories, and a graphical interface for training that classifier by example — so that new recognition systems for unusual or historical documents can be built without starting from scratch. It represents one of DDMAL's earliest and most foundational contributions to optical music recognition (OMR) tooling, predating later tools like Rodan and Neon.
