IMAGE is an ongoing SRL project that lets people who are blind or low-vision experience photographs, charts, and maps on the web through sound and touch instead of sight. A browser extension adds controls to web graphics so a user can trigger a "sonification" (turning visual information into sound) — for example, hearing a beep move around their head through headphones to indicate where an object sits in a photo, or how large it is — sometimes paired with a haptic (touch-based) device like a braille pin-array tablet that lets a user physically feel the shape of a chart. This is a form of sensory substitution: replacing one sense (vision) with information delivered through others (hearing and touch). The project is open source and built as modular "microservices" so outside developers and researchers can build and plug in their own graphic-interpretation tools.
