This is the public code repository for the server-side components of the IMAGE project, SRL's system for making web graphics (photos, charts, maps) accessible to blind and low-vision users through sound and touch. It is written mostly in Python and organized as a set of small, independent "microservices" — separate programs that each handle one small job (like detecting objects in a photo or converting a chart into an audio description) and can be swapped in or out. Making this code open source lets other researchers and developers extend the platform with new ways of translating visual information into audio or haptic (touch) experiences, without having to rebuild the whole system from scratch.
