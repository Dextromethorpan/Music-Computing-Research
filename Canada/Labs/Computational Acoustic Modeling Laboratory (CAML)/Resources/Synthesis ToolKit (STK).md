The Synthesis ToolKit in C++ (STK) is a free, open-source set of C++ building blocks for writing sound-synthesis and audio-processing software. "Synthesis" here means generating sound from scratch with a computer, rather than just playing back a recording. STK was started in 1995 by Perry Cook (Princeton) and Gary Scavone (McGill, CAML's director) and is still maintained today. It gives programmers ready-made pieces — virtual instruments, filters, effects, and real-time audio/MIDI input-output classes — so they don't have to write signal-processing code from zero. It became one of the most widely used teaching and prototyping tools in computer music because it runs on Windows, macOS, and Linux and includes many working examples of "physical modeling" instruments (software that mimics how a real instrument's physical parts vibrate) alongside classic synthesis methods.
