An open-source testing library Focusrite built to help automate "end-to-end" testing of desktop applications built with JUCE, the widely-used C++ framework for audio plugins and applications. Rather than manually clicking through an app's interface to check it still works correctly after a code change, this library lets engineers write automated tests that simulate real user interaction with a JUCE app's controls (knobs, buttons, menus). It's an example of the less glamorous but essential engineering infrastructure that keeps professional audio software reliable as it's updated.
