Open-source materials from a Focusrite engineering talk at the Audio Developer Conference (ADC) 2023, demonstrating step-by-step how to make an audio plugin's user interface properly accessible to screen-reader users (people who are blind or have low vision, using software that reads the screen aloud). The repository's commit history is deliberately structured to show "before" and "after" states, so developers can see exactly what changes made the interface accessible. This is a practical, less-discussed side of music software engineering: making creative audio tools usable by musicians and engineers with visual impairments.
