This is a recorded conference talk from the Audio Developer Conference (ADC) — an annual event run around the JUCE community — in which ROLI's lead developer for the LUMI app explains how the team built the companion learn-to-play app for ROLI's beginner-friendly LUMI Keys keyboard. The challenge was combining three very different toolkits in one app: JUCE (in C++) to handle the actual audio engine reliably in real time, React Native (in JavaScript) for the app's menus and screens, and the Unity game engine (in C#) for the game-like animated visuals that guide a learner's hands on the keyboard. It's a good beginner-friendly window into a real, practical problem in music software engineering — making a consumer app feel slick and game-like while still keeping audio timing sample-accurate underneath.
