JUCE is a free, open-source software toolkit written in the programming language C++ that developers use to build audio applications — things like music production software (DAWs), and especially "plugins": small add-on programs that run inside a DAW to add an instrument or effect. Before JUCE, a developer had to write separate versions of a plugin for every operating system (Windows, Mac) and every plugin format (VST, AU, AAX, and so on); JUCE handles all that "glue" code so one codebase can be exported to all of them. It was originally created by British developer Julian Storer, and ROLI acquired it in 2014 to make Storer's team part of the company and to make JUCE the backbone of ROLI's own products (like the Seaboard's companion software). Today JUCE is one of the most widely used frameworks in the professional audio software industry, and ROLI continues to fund its open-source development and its associated Audio Developer Conference (ADC).
