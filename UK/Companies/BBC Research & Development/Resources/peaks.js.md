peaks.js is an open-source JavaScript component, built by BBC R&D, for displaying and interacting with audio waveforms directly in a web browser — letting users zoom into a waveform, add markers or labelled segments, and play back specific sections. It's designed to pair with the audiowaveform tool for the underlying waveform data. The BBC built and open-sourced it to support in-browser audio editing and annotation tools (for example, for radio production or archive review), and it has become a widely reused building block for other web-based audio applications outside the BBC too.
