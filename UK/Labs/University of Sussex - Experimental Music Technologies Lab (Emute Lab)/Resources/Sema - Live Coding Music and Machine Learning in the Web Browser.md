Sema is an open-source, browser-based playground for "live coding" — writing and editing computer code in real time as a musical performance — that also lets performers build in machine learning and machine listening. Rather than being one fixed programming language, Sema lets people design and try out their own small custom languages for controlling sound and AI models, all running directly in a web browser with no separate software install. It won a Best Paper award at the Web Audio Conference for the underlying audio engine, and has been studied for how well it supports creative experimentation.
