This paper describes the system that won first prize at the DCASE 2017 challenge (an international competition for detecting and classifying real-world sounds) in the "large-scale weakly supervised sound event detection for smart cars" category. The team built a "gated" convolutional neural network — a type of AI model that learns to let through only the parts of an audio signal that are actually useful for the classification task, similar to a filter that learns which details matter. Combined with a technique for roughly locating where in a clip a sound event happens (despite only having coarse "this sound is present somewhere" labels to learn from), the system set a strong early benchmark for large-scale sound event detection and helped establish CVSSP's reputation in the DCASE community.
