This is the open-source dataset and code released alongside the group's jazz harmonic-similarity research: a collection of jazz chord progressions (the sequences of chords that make up a jazz tune) along with the code used to test different ways of measuring how similar two chord progressions are. Making a resource like this public lets other researchers reproduce the results and build their own harmony-analysis tools on real jazz repertoire instead of starting from scratch.
