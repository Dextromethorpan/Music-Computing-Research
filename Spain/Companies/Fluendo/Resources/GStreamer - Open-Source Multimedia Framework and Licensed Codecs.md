GStreamer is a widely used free, open-source toolkit that software developers use to build programs that play, stream, edit, or convert audio and video — think of it as a set of interchangeable building blocks ("plugins") that you connect together into a pipeline, one block per processing step. A tricky part of working with audio/video is that many common formats (codecs) are covered by patents, so a company that wants to ship a product using them legally needs a license. Fluendo's business bridges this gap: it builds and maintains parts of the GStreamer ecosystem and provides a set of codec plugins that already include the necessary patent licenses, so other companies can use them commercially without arranging separate licensing deals themselves. This page documents Fluendo's role as both an open-source contributor to the underlying framework and a licensed-codec vendor, spanning both audio and video processing.
