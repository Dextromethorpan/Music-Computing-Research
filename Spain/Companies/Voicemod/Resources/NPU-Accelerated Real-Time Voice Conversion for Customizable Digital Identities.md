This is a "Show and Tell" demo abstract accepted for the IEEE ICASSP 2026 conference (a major signal-processing research conference, held in Barcelona), presented by Voicemod's R&D team. It describes a real-time voice conversion system redesigned to run on NPUs (Neural Processing Units — specialized chips built into modern laptops and phones for running AI models efficiently, separate from the main processor or graphics card), instead of relying on a cloud server or graphics card. Moving to NPUs lets Voicemod use larger, more complex AI models than before while still running with low delay on ordinary consumer devices. The demo also lets people design a voice using simple, intuitive sliders — for qualities like age, gender, depth, and breathiness — or by typing a text description (e.g. "a deep, gravelly, yet smooth voice"), instead of needing technical audio knowledge.
