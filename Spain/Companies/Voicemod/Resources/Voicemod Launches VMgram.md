This December 2023 press release announced VMgram, Voicemod's first mobile app and its first direct integration into a third-party communications platform (Telegram). It let users apply Voicemod's real-time AI voice changing and a large soundboard (over 150,000 pre-made sound clips) during Telegram voice and video calls and in voice messages, initially on Android. Technically, it was built by combining Voicemod's own software development kit (SDK — a package of tools other apps can use to add Voicemod's voice tech) with Telegram's open-source code, showing that Voicemod's real-time voice conversion could run inside someone else's mobile app rather than only its own desktop software.
