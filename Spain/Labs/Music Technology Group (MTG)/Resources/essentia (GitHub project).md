This is the actual open-source codebase behind Essentia, MTG's audio analysis toolkit, freely downloadable and still actively maintained. It is written mainly in C++ with a Python interface, so both researchers and software developers can use it. Beyond basic descriptors, the project now also ships pre-trained machine-learning models (for example, for detecting music genre, mood, or instruments) that anyone can plug into their own programs. A companion project, essentia.js, brings the same analysis tools into web browsers using WebAssembly, so audio analysis can run directly on a webpage without installing anything.
