This paper introduces Essentia, a free software toolkit that lets a computer "listen" to an audio file and pull out useful information from it — things like tempo, key, loudness, and hundreds of other measurable properties of the sound. Instead of every research team writing this analysis code from scratch, Essentia packages it into reusable building blocks that can be combined to build bigger audio applications. It has become one of the most widely used tools in the sound-and-music-computing field, powering research projects, music apps, and MTG's own Freesound search engine. The paper describes the library's design and shows example uses in tasks like automatic tagging and instrument detection.
