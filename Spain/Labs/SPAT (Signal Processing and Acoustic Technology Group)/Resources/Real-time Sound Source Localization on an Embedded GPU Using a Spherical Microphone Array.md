A spherical microphone array is a ball-shaped cluster of many microphones that can sense sound arriving from any direction in 3D space, which is useful for figuring out exactly where a sound is coming from. Normally, the calculations needed to do this in real time require a lot of computing power. This paper shows how to run those calculations fast enough for real-time use on an embedded GPU (a small, low-power graphics processor, the kind found in compact devices rather than a full desktop computer), making this kind of 3D sound localization practical for portable or embedded hardware rather than only powerful lab computers.
