musicaiz is a free, open-source software toolkit (written in the Python programming language) for working with symbolic music — that is, music stored as note/score data, such as MIDI files, rather than as recorded audio. It lets researchers load MIDI files, represent musical structure (notes, bars, instruments, chords, keys), convert music into "tokens" so it can be fed into deep-learning models, and evaluate AI music-generation systems. It was described in a companion paper published in the journal SoftwareX. The library is actively used inside the lab's other research, such as the graph-based structure-analysis method described in a related paper.
