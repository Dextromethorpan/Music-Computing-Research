SysSon is a software platform, developed at IEM and funded by the Austrian Science Fund (FWF), for "sonification" — the practice of turning data into sound instead of (or alongside) charts and numbers. It was built specifically to help scientists explore large datasets (its original use case was climate and atmospheric science data) by systematically mapping numbers to audible qualities like pitch, loudness, or timbre, so patterns can be heard rather than only seen. The project is written in Scala and is open source under the GNU General Public License. Development was later continued with support from the Austrian Knowledge Transfer Centre. The GitHub repository is now archived (read-only), meaning active development has stopped, but the source code and documentation remain publicly available.
