ambix is an open-source software library that helps different audio programs agree on how to store and label Ambisonics audio files. Ambisonics (see the Ambisonics concept note) encodes sound direction across a small number of numbered channels, but different software historically ordered and scaled those channels differently, causing compatibility problems. ambix provides a shared, standardized way to read and write these files (using metadata tags) so recordings made in one Ambisonics tool play back correctly in another. The library is written in C and distributed under the LGPL-2.1 open-source license; the version hosted under IEM's GitHub organization is a maintained mirror of the original project.
