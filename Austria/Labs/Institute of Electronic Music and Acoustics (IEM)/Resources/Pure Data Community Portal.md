Pure Data ("Pd") is a free, visual (drag-and-drop, wire-based) programming language for building custom audio, video, and sensor-driven software without writing lines of text-based code — musicians and researchers connect little on-screen boxes with virtual "patch cords" instead. IEM hosts and runs puredata.info, the main community website and mailing lists for the worldwide Pd community, even though Pd itself was created by Miller Puckette. IEM has long been a hub for Pd development: IEM staff member IOhannes m zmölnig is a core Pd developer, and the institute has produced several widely used Pd extension libraries (such as iemlib, zexy, and iemguts) that add extra building blocks to the language.
