Sheet music can be stored as a computer file using a standard called MEI (Music Encoding Initiative), which describes notes, rhythms and symbols in a machine-readable text format, similar to how HTML describes a webpage. Editing these files by hand used to require specialist tools. "mei-friend" is a free, browser-based editor the IWK team built so researchers and musicians can view and edit MEI music encodings directly in a web browser, with a music notation preview updating live. This paper, published in the Journal of the Text Encoding Initiative, documents the tool. It is closely tied to the IWK's broader work on digital music research infrastructure led by Werner Goebl and David M. Weigl.
