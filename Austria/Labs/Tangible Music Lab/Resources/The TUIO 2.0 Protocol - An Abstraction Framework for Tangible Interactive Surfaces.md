This paper introduces an updated, more capable version of the TUIO protocol (the original "language" for describing objects and touches on an interactive tabletop, created by the same lab in 2005). TUIO 2.0 adds support for describing more complex interactive surfaces — like ones that sense pressure, multiple layered objects, or non-flat shapes — while staying compatible with the huge range of software already built around the original TUIO standard. It is essentially an engineering paper about designing a good, future-proof communication format, aimed at other researchers and developers building tangible (physically touchable) interactive systems. This work grew directly out of Martin Kaltenbrunner's doctoral dissertation on the same topic.
