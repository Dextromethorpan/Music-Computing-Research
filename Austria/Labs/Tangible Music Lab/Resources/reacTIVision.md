reacTIVision is a free, open-source computer program that lets a normal camera "see" small paper tags (called fiducial markers) stuck onto physical objects, so a computer can track exactly where each object is on a table and how it is rotated. It also tracks fingertips touching the same surface. It sends everything it detects out using the TUIO protocol, so other software (music apps, games, art installations) can react in real time to people moving objects around on a tabletop. This is the actual vision engine that powers the reacTable, a tangible tabletop synthesizer where each physical block represents a piece of a sound-generating patch. "Tangible" here means you interact with software by physically moving real objects, instead of only tapping a screen or using a mouse.
