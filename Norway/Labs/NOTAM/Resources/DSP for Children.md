This is an educational software tool built by NOTAM that teaches digital signal processing (DSP — the math and techniques behind manipulating sound digitally) to school-age children through hands-on sound experiments rather than lectures. It runs in a web browser and combines simple composition exercises with tutorial material, aiming to make abstract concepts like frequency and waveforms tangible by letting children hear the effect of changing them directly.
