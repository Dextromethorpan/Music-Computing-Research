This is the lab's public code repository, where it shares the actual software tools it builds for its research — for example, an application called VideoAnalysis that extracts motion information directly from ordinary video files (rather than requiring expensive motion-capture cameras), so other researchers can measure body movement in music performance more cheaply. Publishing this kind of tool lets outside researchers reproduce or build on fourMs's methods.
