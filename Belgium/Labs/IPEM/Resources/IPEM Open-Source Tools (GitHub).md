This is IPEM's public code repository, where the lab shares the software tools it builds for its research. These include programs for analysing body movement synchronised with music (for example, from motion-capture suits or smartphone sensors) and toolkits used in its "ArtScienceInteractionLab", a space where researchers and artists experiment together with new digital technology. Sharing this code lets other music researchers and students reuse IPEM's measurement and analysis methods instead of building them from scratch.
