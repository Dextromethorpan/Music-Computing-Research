This paper introduces ChucK, a programming language built specifically for making music and sound in real time. Unlike most programming languages, ChucK lets a musician add, change, or remove lines of code while the program is already running and making sound — a technique called "live coding" or "on-the-fly programming," similar to editing a song's script as it plays instead of writing it all in advance. The paper explains how ChucK gives very precise control over timing, so notes and events happen exactly when intended, and how it can run many musical processes at once (for example, separate instrument voices). The work won a 2004 ACM Multimedia Open Source Software Competition award and became the technical backbone of much of the Sound Lab's later work.
