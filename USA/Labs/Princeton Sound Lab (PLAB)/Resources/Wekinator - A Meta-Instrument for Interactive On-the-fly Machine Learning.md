This paper introduces an early version of Wekinator, a tool that lets musicians teach a computer to recognize their gestures — from sensors, cameras, or controllers — and turn them into musical control signals, using machine learning (a method where a computer "learns" patterns from examples rather than being explicitly programmed with rules). Instead of writing code that maps a physical motion to a sound parameter, a performer can demonstrate examples (for instance, "when I move like this, the pitch should go up") and the software learns the pattern. Presented at NIME 2009, the paper frames this as a way of building new "meta-instruments" — tools for creating instruments — useful for both live performance and instrument-design experimentation.
