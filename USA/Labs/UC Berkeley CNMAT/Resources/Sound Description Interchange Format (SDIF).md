SDIF is a standard file format, jointly developed by CNMAT and IRCAM in the mid-1990s, for storing and sharing "sound descriptions" — the results of analyzing a sound, such as its changing pitch, its individual sinusoidal partials (component sine waves), or other spectral models — rather than the raw audio itself. Before SDIF, different research labs' analysis software mostly used incompatible, custom file formats, making it hard to share analysis data or combine tools from different institutions. Standardizing this data let different computer-music software (for analysis, synthesis, and composition) built at different institutions actually work together.
