Nyquist is a programming language, built by Roger Dannenberg at CMU, for both designing sound-generating "instruments" and composing music with them in the same language. It's built on Lisp (a programming language known for treating code and data very similarly), and lets a user combine small building-block functions into custom synthesizers, then write out a piece by calling those instruments with different notes and timings — unlike many computer music systems that keep instrument-design and composition as two separate steps. Nyquist has been maintained and used for both research and teaching at CMU for decades, and it also became the scripting language behind Audacity, the popular free audio editor.
