pyACA is a free, open-source Python software package that provides working, ready-to-use code for the standard techniques described in Alexander Lerch's audio content analysis textbook. In plain terms, it is a toolbox that lets a programmer measure properties of a sound file — things like pitch (fundamental frequency), loudness-related brightness, chord content, or where distinct musical notes begin (onset detection) — without having to implement the underlying signal-processing math from scratch. It exists alongside sister versions in other programming languages (libACA and ACA-Code), all documented together in a companion research paper, so students and engineers can use whichever language they already work in. Publishing this kind of reference code openly helps the wider Music Information Retrieval research community build and compare new methods on a shared, well-tested foundation.
