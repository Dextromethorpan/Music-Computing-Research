Audacity is a free, extremely popular audio editing program (over 100 million downloads). This project built a software framework that lets AI researchers plug their own machine learning models (built using the popular PyTorch programming toolkit) directly into Audacity, the same way a plug-in or effect would work. Researchers upload a trained model to Hugging Face (a public hosting site for AI models), and it then appears inside Audacity's menus for anyone to use, no special installation or coding required by the end user. This closes the gap between cutting-edge audio AI research and the software actual musicians and sound editors use every day — for example, allowing one-click AI-based source separation (splitting a song into vocals, drums, etc.) right inside Audacity.
