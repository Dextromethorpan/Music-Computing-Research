nussl (pronounced "nuzzle") is a free, open-source Python software library that lets programmers isolate individual sounds from an audio mixture — for example, pulling the vocals or drums out of a finished song. It bundles together many different published source-separation algorithms behind one easy-to-use interface, so a researcher can try several approaches on the same audio without rewriting code each time. It also ships with pre-trained models people can download and use directly, plus support for common research datasets used to test separation quality. This makes it a widely used starting point for anyone building or studying source-separation software.
