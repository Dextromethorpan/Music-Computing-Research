STK (Synthesis ToolKit) is a free, open-source set of reusable programming building blocks (a "toolkit") written in the C++ language, for building software that synthesizes sound. It includes ready-made code for "physical modeling" instruments — simulations of real instruments like flutes, plucked strings, and drums, built from equations describing how they vibrate — plus tools for filters, reverb, and MIDI control. STK has been used since the mid-1990s by researchers, students, and hobbyists worldwide as a starting point for building their own synthesizers and music software rather than writing signal-processing code from scratch.
