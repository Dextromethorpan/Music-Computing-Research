This is the free, open-source codebase for ChucK, a music programming language developed and maintained by CCRMA. ChucK is designed so a person can type audio-generating code and hear the result change immediately, making it popular for "live coding" concerts where the audience watches code turn into sound. It also underlies teaching tools and the Stanford Laptop Orchestra. Anyone can download it, read its source code, and contribute improvements, which is why it counts as an open-source research tool rather than a commercial product.
