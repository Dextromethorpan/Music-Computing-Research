This is a free, hands-on educational resource for learning how a computer can process music. "Music processing" means using math and code to analyze recordings — for example, figuring out the tempo, finding repeating sections, or recognizing chords. The FMP (Fundamentals of Music Processing) notebooks let a total beginner run real Python code side by side with plain-language explanations, so you can see exactly how an algorithm turns a sound wave into numbers and back again. The notebooks are built around Meinard Müller's textbook of the same name and are widely used worldwide to teach Music Information Retrieval (MIR), the field concerned with getting computers to understand and organize music.
