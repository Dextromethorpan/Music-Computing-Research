libfmp is a downloadable Python toolbox — a "starter kit" of code — that packages standard music-analysis algorithms into clean, documented functions anyone can call. These are the kinds of algorithms used to detect chords, tempo, or the structure (like verse/chorus) of a song from an audio recording. It complements the popular librosa audio library and reimplements older MATLAB research tools in Python so they're easier to use and teach with. It exists specifically to help students move from "understanding the theory" to "being able to build their own audio analysis programs," since every function ties directly back to explanations in the companion FMP notebooks and textbook.
