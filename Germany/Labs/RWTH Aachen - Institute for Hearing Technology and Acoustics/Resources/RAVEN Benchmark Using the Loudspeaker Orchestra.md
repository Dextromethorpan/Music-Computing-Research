RAVEN ("Room Acoustics for Virtual EnvironmentsN") is a room-acoustics simulation software developed at this institute over many years; it computes how sound bounces around a virtual room so it can be turned into realistic, listenable audio (auralization). This paper checks how accurate RAVEN's predictions are by comparing them against real recordings made with a "loudspeaker orchestra" — an array of individually controllable loudspeakers, each playing back one instrument's part, arranged like a real orchestra in a real room — used as a physical benchmark for validating acoustic simulations.
