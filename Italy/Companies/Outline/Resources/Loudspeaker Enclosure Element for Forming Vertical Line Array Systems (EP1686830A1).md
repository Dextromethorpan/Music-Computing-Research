"Directivity" describes which direction a loudspeaker throws its sound most strongly. This European patent covers a loudspeaker enclosure built for stacking into a vertical line array (a tall column of identical speakers) whose horizontal and vertical directivity can both be adjusted after the array is assembled — letting installers tune coverage area both side-to-side and up-down, rather than being locked into one fixed dispersion pattern set at the factory.
