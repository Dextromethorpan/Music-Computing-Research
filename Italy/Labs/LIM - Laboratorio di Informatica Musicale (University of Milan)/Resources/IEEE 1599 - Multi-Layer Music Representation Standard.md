IEEE 1599 is a file format, built on XML (a structured text format computers can read and organize), that lets one single digital file hold several different "layers" describing the same piece of music at once: the printed score, an audio recording, a MIDI performance, and background information, all cross-linked and kept in sync with each other. In plain terms, it lets software jump seamlessly between "what the score looks like," "what it sounds like," and "how it was actually performed" for the exact same piece, instead of treating those as separate, disconnected files. This is LIM's flagship, long-running research output and became an official IEEE standard.
