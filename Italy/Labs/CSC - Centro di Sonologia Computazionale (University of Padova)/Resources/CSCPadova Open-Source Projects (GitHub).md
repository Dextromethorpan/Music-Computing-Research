This is CSC's public collection of code on GitHub (a website where programmers share and collaborate on software). It includes projects like `wav2taste`, which uses machine learning (software that learns patterns from data) to predict what taste or flavor a piece of music might evoke in a listener, and `lilybert`, a language model trained on LilyPond (a text format used to write down musical scores) so it can generate or understand written music the way text-generating AI understands sentences. There are also tools for restoring and equalizing old analogue tape recordings. It's a good place for a beginner to see actual runnable research code rather than just reading about it in a paper.
