"Virtual analog" means digitally simulating old analogue hardware — like a vintage guitar pedal or amplifier — so that it can run entirely as software instead of a physical circuit. "Wave Digital Filters" are a mathematical technique for accurately modeling the actual electronic circuits inside that old hardware, component by component, rather than just imitating its overall sound. VIOLA is an open-source toolkit (freely available code on GitHub) that automatically converts a circuit diagram into a working audio plug-in using this technique, so a developer doesn't have to hand-derive the underlying equations for every new circuit.
