MIDI is a common file format that stores music as a set of instructions (which notes, how loud, how long) rather than as recorded audio. MidiCaps is a large public dataset that pairs over 168,000 MIDI files with plain-English text descriptions of their musical content — tempo, chord progression, time signature, instruments used, genre, and mood. The captions were generated by extracting musical features from each file and its synthesized audio, then using an AI language model to turn those features into natural-sounding descriptions. It is meant to help train and test AI systems that translate between text and symbolic music, such as text-to-MIDI generation or music search by description.
