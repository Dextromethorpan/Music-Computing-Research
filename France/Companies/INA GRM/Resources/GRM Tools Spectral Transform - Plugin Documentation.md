GRM Tools Spectral Transform is a set of four audio plugins built on decades of research at GRM into breaking a sound down into its individual frequency components (its "spectrum") and reshaping them in creative ways. For example, "Contrast" groups a sound's frequencies by how loud each one is and lets you boost or reduce each group separately, which can make an old recording sound richer or a sound turn strange and metallic. "FreqWarp" lets you move frequency components to completely different positions, radically changing a sound's character. This page documents the specific, named techniques inside the plugin bundle, which trace back to spectral-processing methods GRM's engineers built for real-time use starting in the 1990s.
