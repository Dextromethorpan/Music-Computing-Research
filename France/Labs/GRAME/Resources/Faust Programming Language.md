Faust (Functional Audio Stream) is a specialized programming language, started in 2002 and actively maintained by GRAME's research department, made specifically for writing audio effects, synthesizers, and instruments. Instead of writing lots of general-purpose code, you describe how sound signals should flow and combine using short mathematical-style expressions, and Faust's compiler turns that description into fast, efficient code for many targets (C++, WebAssembly for web browsers, plug-in formats, even FPGA hardware chips). This lets a single Faust program become a working plug-in, a mobile app, or an embedded hardware instrument with minimal changes, which is why it's widely used in both academic audio research and commercial audio products.
