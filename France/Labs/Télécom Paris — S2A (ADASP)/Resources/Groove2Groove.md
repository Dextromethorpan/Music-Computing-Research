Imagine feeding a computer a simple melody and telling it "play this like a jazz band" or "play this like an 80s pop backing track," and having it generate a whole new instrumental accompaniment in that style — that's what Groove2Groove does. It is a machine-learning system for "style transfer" in music, meaning it can take the accompaniment of one song and rewrite it in the style of another, using only a single short example of the target style (a "one-shot" transfer, meaning it doesn't need dozens of examples to learn the new style). The system was trained on a large synthetic dataset the same team built (covering roughly 3,000 different musical styles) so it could generalize to sounds it hadn't seen before. The project includes downloadable code and audio demos so the results can be heard directly.
