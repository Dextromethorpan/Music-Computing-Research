Prompt Sampler is a free, open-source plugin (a piece of software that runs inside music-production programs) that lets a musician type a text description — like "gritty lo-fi drum loop" — and get back a matching short audio sample. It's built on Meta's open-source AudioGen model (a type of AI trained to generate sound from text descriptions) and runs entirely on the user's own computer, so no audio or personal data is sent to an outside server.
